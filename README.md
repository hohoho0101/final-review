# 期末复习方案 · 微积分 / 线性代数 / C++

华南理工大一上学期期末复习网站，整个网站只有一个 `index.html`，没有任何外部依赖，国内打开也快。

## 里面有什么

- **计划与每日题**：考试倒计时；每日三题（7 周 × 5 天 × 3 科，共 105 道，解析默认折叠）；九周计划（可打勾）。
- **微积分指南**：对应《高等数学（上册）》（华南理工大学数学系编，高等教育出版社）第一至五章。
- **线性代数指南**：对应《线性代数与解析几何》（华南理工大学数学学院编，高等教育出版社）第一至六章，节号与课本一致。
- **C++ 指南**：对应《C++ 程序设计基础（第 6 版）》（周霭如等，电子工业出版社）第 1–5 章。

每本指南按“概念 → 公式 → 例题 → 难点 → 自测题”编排，最后一章是考前速查。C++ 的“运行结果”都是程序实际编译运行得到的。

## 部署到 GitHub Pages

1. 打开仓库，**Add file → Upload files**，把 `index.html` 拖进去，**Commit changes**。
   - 文件名必须正好是 `index.html`。如果下载下来叫 `index_1.html` 或 `index (1).html`，先在电脑上改名再上传，才能覆盖旧文件。
2. 第一次部署：仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`、`/ (root)`，**Save**。
3. 等一两分钟，打开 `https://你的用户名.github.io/仓库名/`，按 Ctrl+F5 刷新。

也可以直接双击 `index.html` 在本地浏览器打开，功能完全一样。

## 怎么改

- **考试日期**：在网页的倒计时卡片里改，自动保存（只对当前浏览器有效）。想改所有人看到的默认日期，在 `index.html` 里搜索 `DEFAULT_DATES`。
- **每周任务**：搜索 `const WEEKS`，改引号里的文字。
- **指南里的文字**：搜索那句话直接改。

## 说明

- 打勾、“做完了”“学完了”的记录保存在浏览器的 localStorage 里，换设备或清缓存会丢失。
- 指南按教材章节顺序独立编写，不是课本原文。考试范围、题型和日期以任课老师和教务处通知为准。
