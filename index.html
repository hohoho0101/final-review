微积分Ⅰ(一) 考点地图

范围：函数、极限与连续 → 导数与微分 → 中值定理与导数应用 → 不定积分 → 定积分 → 定积分应用。星级 = 期末重要程度。

极限与连续
★★★★★
  • 求极限的武器库：代入 / 约分 / 有理化 → 等价无穷小（只在乘除因子中替换）→ 洛必达（每用一次都要检查是不是 0/0 或 ∞/∞）→ 泰勒展开（加减项里没法等价替换时用）
  • 1∞ 型：lim fg = elim (f−1)·g；∞−∞ 型先通分；0·∞ 型化成分式
  • 数列极限：夹逼准则、单调有界准则（常考递推数列）
  • 间断点分类：第一类（可去、跳跃）、第二类（无穷、振荡）——先找“没定义的点”和分段点
导数与微分
★★★★
  • 分段函数在分段点处必须用定义求导，并分左右导数
  • 复合函数链式法则、隐函数求导、对数求导法（幂指函数 uv）
  • 参数方程二阶导：d²y/dx² = [d(dy/dx)/dt] ÷ (dx/dt)（最容易漏除 dx/dt）
  • 高阶导数：找规律或莱布尼茨公式；可导 ⇒ 连续，反之不成立
中值定理与导数应用
★★★★★
  • 罗尔 / 拉格朗日 / 柯西：证明题的关键是构造辅助函数（见下方速查表）
  • 用单调性证明不等式：设 F(x)=左−右，求导判号，看端点值
  • 极值与最值、凹凸性与拐点、渐近线（水平 / 铅直 / 斜）——常出综合大题
  • 泰勒公式（带佩亚诺余项）用于求极限、确定无穷小阶数
不定积分
★★★★
  • 凑微分（第一换元）是最常用的；看到 f(φ(x))φ′(x) 就凑
  • 第二换元：√(a²−x²) → x=a sin t；√(a²+x²) → x=a tan t；√(x²−a²) → x=a sec t；根式 ⁿ√(ax+b) 直接令为 t
  • 分部积分选 u 的顺序：反对幂三指（反三角 > 对数 > 幂 > 三角 > 指数，越靠前越适合当 u）
  • 有理函数：先拆部分分式；三角有理式考虑万能代换（最后手段）
定积分
★★★★★
  • 换元必须同时换上下限；对称区间先看奇偶性（奇函数积分为 0）
  • 变限积分求导：d/dx ∫aφ(x) f(t)dt = f(φ(x))·φ′(x)，常和洛必达一起出极限题
  • 被积函数里含 x 时先把 x 提到积分号外再求导
  • 反常积分：无穷限、瑕积分的敛散判断，p-积分结论要背
定积分应用
★★★
  • 平面图形面积（先画图找交点）；旋转体体积：圆盘法 V=π∫f²(x)dx，柱壳法 V=2π∫x|f(x)|dx（绕 y 轴）
  • 曲线弧长 s=∫√(1+y′²)dx；物理应用（做功、压力）看老师有没有讲

公式速查

x → 0 时的等价无穷小
sin x ~ tan x ~ arcsin x ~ arctan x ~ x
ln(1+x) ~ ex−1 ~ x　　ax−1 ~ x ln a
1−cos x ~ x²/2　　(1+x)α−1 ~ αx
x − sin x ~ x³/6　　tan x − x ~ x³/3
x − ln(1+x) ~ x²/2
常用泰勒展开（到 x³）
ex = 1 + x + x²/2 + x³/6 + o(x³)
sin x = x − x³/6 + o(x³)
cos x = 1 − x²/2 + x⁴/24 + o(x⁴)
ln(1+x) = x − x²/2 + x³/3 + o(x³)
(1+x)α = 1 + αx + α(α−1)x²/2 + o(x²)
中值定理证明：辅助函数怎么造
要证的式子长这样试试构造
f′(ξ) + f(ξ) = 0F = exf(x)
f′(ξ) + λf(ξ) = 0F = eλxf(x)
ξf′(ξ) + f(ξ) = 0F = x f(x)
ξf′(ξ) − f(ξ) = 0F = f(x) / x
f′(ξ)g(ξ) + f(ξ)g′(ξ) = 0F = f(x)g(x)

套路：把 ξ 换成 x，看成某个乘积 / 商的导数，再对 F 用罗尔定理。

积分必背
∫ 1/(a²+x²) dx = (1/a) arctan(x/a) + C
∫ 1/√(a²−x²) dx = arcsin(x/a) + C
∫ 1/(x²−a²) dx = (1/2a) ln|(x−a)/(x+a)| + C
∫ sec x dx = ln|sec x + tan x| + C
∫0π/2 sinnx dx = ∫0π/2 cosnx dx（华里士公式）
∫1+∞ 1/xp dx：p>1 收敛，p≤1 发散
易错提醒：等价替换只能替换乘除因子，不能替换加减中的某一项；洛必达不能用于数列（要先换成函数）；不定积分别忘了 +C；定积分换元别忘了换限。

线性代数 考点地图

主线：行列式 → 矩阵 → 向量组与线性方程组 → 特征值与相似对角化 → 二次型。秩是贯穿全书的核心概念。

行列式
★★★★
  • 性质：换两行变号、某行乘 k 则值乘 k、倍加不变——计算主要靠“化上三角”
  • 常见题型：行和相等（各列加到第一列再提公因子）、爪形 / 箭形、范德蒙德、按行展开降阶
  • 克拉默法则；代数余子式线性组合 A₁₁+A₁₂+… 等于把第一行换成系数后的行列式
矩阵
★★★★★
  • 乘法不满足交换律；AB=O 推不出 A=O 或 B=O
  • 求逆：(A | E) → 初等行变换 → (E | A⁻¹)；二阶直接用伴随（主对角互换、副对角变号）
  • 矩阵方程 AX=B：(A | B) → (E | X)；XA=B 则先转置或右乘 A⁻¹
  • 伴随矩阵、分块矩阵、初等矩阵（左乘变行、右乘变列）、矩阵的秩
向量组与线性方程组
★★★★★
  • 线性相关 ⇔ 以向量为列的矩阵秩 < 向量个数
  • 极大无关组：按列排成矩阵，只做初等行变换化行阶梯，主元所在列即为所求
  • 齐次 Ax=0：基础解系含 n − r(A) 个向量
  • 非齐次 Ax=b 通解 = 特解 + 齐次通解；含参数方程组讨论解的情况几乎必考
特征值与相似对角化
★★★★★
  • |λE − A| = 0 求特征值，(λE − A)x = 0 求特征向量（基础解系）
  • 可对角化 ⇔ 有 n 个线性无关的特征向量 ⇔ 每个 k 重特征值恰有 k 个线性无关特征向量
  • 实对称矩阵：一定可以正交相似对角化——同一特征值的向量要施密特正交化，再全部单位化
  • 利用 A = PΛP⁻¹ 求 Aⁿ
二次型
★★★★
  • 写矩阵：平方项系数放对角线，交叉项系数除以 2 放两边
  • 正交变换化标准形（就是实对称矩阵正交对角化）、配方法、惯性定理
  • 正定判定：顺序主子式全 > 0 ⇔ 特征值全 > 0（含参数求范围的题常考）
空间解析几何
（若课程名含“解析几何”）
★★★
  • 数量积、向量积、混合积（平行六面体体积）；平面、直线方程与位置关系；点到平面 / 直线距离
  • 常见二次曲面识别（椭球面、单 / 双叶双曲面、抛物面、锥面）

struct Node { int data; Node *next; };

// 尾插法建表：输入若干正整数，以 0 结束
Node* create() {
    Node *head = nullptr, *tail = nullptr; int x;
    cin >> x;
    while (x != 0) {
        Node *p = new Node; p->data = x; p->next = nullptr;
        if (head == nullptr) head = p; else tail->next = p;
        tail = p;
        cin >> x;
    }
    return head;
}

// 遍历
void print(Node *head) {
    for (Node *p = head; p != nullptr; p = p->next) cout << p->data << ' ';
}

// 在升序链表中插入，保持有序
Node* insert(Node *head, int x) {
    Node *s = new Node; s->data = x;
    if (head == nullptr || x < head->data) { s->next = head; return s; }
    Node *p = head;
    while (p->next != nullptr && p->next->data < x) p = p->next;
    s->next = p->next;   // 先接后面
    p->next = s;         // 再接前面（顺序不能反！）
    return head;
}

// 删除第一个值为 x 的结点
Node* remove(Node *head, int x) {
    if (head == nullptr) return head;
    if (head->data == x) { Node *t = head; head = head->next; delete t; return head; }
    Node *p = head;
    while (p->next != nullptr && p->next->data != x) p = p->next;
    if (p->next != nullptr) { Node *t = p->next; p->next = t->next; delete t; }
    return head;
}
// 冒泡排序（升序）
void bubble(int a[], int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1]) { int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t; }
}

// 选择排序（升序）
void selectSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int k = i;
        for (int j = i + 1; j < n; j++) if (a[j] < a[k]) k = j;
        if (k != i) { int t = a[i]; a[i] = a[k]; a[k] = t; }
    }
}

// 二分查找（a 已升序），找不到返回 -1
int bsearch(int a[], int n, int x) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x) lo = mid + 1; else hi = mid - 1;
    }
    return -1;
}

void sortDesc(Student s[], int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (s[j].score < s[j + 1].score) { Student t = s[j]; s[j] = s[j + 1]; s[j + 1] = t; }
}

int main() {
    int n; cin >> n;
    Student *s = new Student[n];          // 动态内存分配
    for (int i = 0; i < n; i++) cin >> s[i].id >> s[i].name >> s[i].score;
    sortDesc(s, n);
    for (int i = 0; i < 3 && i < n; i++)    // 别忘了 n < 3 的情况
        cout << s[i].id << " " << s[i].name << " " << s[i].score << endl;
    delete[] s;                            // new[] 对应 delete[]
    return 0;
}

程序阅读 / 选择题高频陷阱

  • 5/2 结果是 2；5/2.0 才是 2.5
  • if (a = 0) 是赋值，条件永远为假
  • char a[10] = '5'; 错误；char a[] = "abc"; 长度是 4（含 '\0'）
  • 函数参数里的 int a[] 其实是指针，sizeof(a) 不是数组大小
  • 数组下标从 0 到 n−1，a[n] 越界
  • && / || 短路：左边已能决定结果时右边不执行（右边的 i++ 不会发生）
  • static 局部变量只初始化一次，多次调用会累积
  • 引用参数 int &a 会改到实参，值参数不会——阅读题先标出谁是引用
  • switch 匹配后一直往下执行直到 break
  • for(...); 末尾多了分号，循环体是空语句
  • new[] 配 delete[]；删除链表结点前先保存 next
  • 全局变量和局部变量同名时，函数内用的是局部的（::x 才是全局）
程序阅读做法：在草稿纸上画一张“变量表”，每执行一行就更新一次值；遇到函数调用就另起一列，写清楚参数是拷贝还是引用；递归画调用树。不要靠“感觉”猜输出。
编程题做法：先写 #include、main 框架和变量声明，再写核心逻辑；就算算法没写完，框架、输入输出也有步骤分。
